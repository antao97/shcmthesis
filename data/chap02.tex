\chapter{\LaTeX{} 使用介绍}

LaTeX（读作/ˈlɑːtɛx/或/ˈleɪtɛx/）是一个让你的文档看起来更专业的排版系统，而不是文字处理器。它尤其适合处理篇幅较长、结构严谨的文档，并且十分擅长处理公式表达。它是免费的软件，对大多数操作系统都适用。

LaTeX 基于 TeX（Donald Knuth 在 1978 年为数字化排版设计的排版系统）。TeX 是一种电脑能够处理的低级语言，但大多数人发现它很难使用。LaTeX 正是为了让它变得更加易用而设计的。目前 LaTeX 的版本是 LaTeX 2e。

如果你习惯于使用微软的 Office Word 处理文档，那么你会觉得 LaTeX 的工作方式让你很不习惯。Word 是典型的「所见即所得」的编辑器，你可以在编排文档的时侯查看到最终的排版效果。但使用 LaTeX 时你并不能方便地查看最终效果，这使得你专注于内容而不是外观的调整。

一个 LaTeX 文档是一个以 \file{.tex} 结尾的文本文件，可以使用任意的文本编辑器编辑，比如 Notepad，但对于大多数人而言，使用一个合适的 LaTeX 编辑器会使得编辑的过程容易很多。在编辑的过程中你可以标记文档的结构。完成后你可以进行编译——这意味着将它转化为另一种格式的文档。它支持多种格式，但最常用的是 PDF 文档格式。

LaTeX 可以使用 TeXPage 进行在线编译，或者使用已有的 TeX 软件进行本地编译。如果是初学者对于安装 TeX 软件并不熟悉，推荐使用 TeXPage 在线编译。

\section{使用 TeXPage 在线编译}

TeXPage 是一个在线 LaTeX 编辑平台，可以免费注册和使用，不用下载 LaTeX 软件，即可在线编辑和编译 LaTeX 文档。

\subsection{打开文件流程}

打开 TeXPage 网站上的模板即可直接使用，网址：\url{https://www.texpage.com/zh/template/2387f991-a81e-416f-ae68-2e0085f97310/}

\subsection{使用介绍}

1. 更改文本内容之后，可以重新进行编译生成 PDF 文件。

2. 由于 TeXPage 为在线编译器，网站可能会出现故障（很少见），因此建议随时做好备份，可以随时下载全部文件或者生成的 PDF 文件。

\section{使用 TeX 本地编译}

对于 Windows 用户，你需要下载 TeX Live 或 MikTeX。国内用户可以使用清华大学 TUNA 镜像站（\url{https://mirrors.tuna.tsinghua.edu.cn/}），请点击页面右侧的「获取下载链接」按钮，并选择「应用软件」标签下的「TeX 排版系统」即可下载 TeX Live 或 MikTeX 的安装包，其中 TeX Live 的安装包是一个 ISO 文件，需要挂载后以管理员权限执行 install-tl-advanced.bat。

对于 macOS 用户，清华大学 TUNA 镜像站同样提供 MacTeX 和 macOS 版 MikTeX 的下载。

对于 Linux 用户，如果使用 TeX Live，则同样下载 ISO 文件，执行 install-tl 脚本；如果使用 MikTeX，则按照官方文档（\url{https://miktex.org/download\#unx}）进行安装。

安装完成后，同样需要选择编译器为 XeLaTex。

\section{模板结构介绍}

下面介绍本模板的各个文件的功能和使用方式。

\subsection{全局信息设置}

本模板的标题作者信息设置位于 \file{shcmsetup.tex}，请根据自己的信息进行修改。

需要设置的变量如下：

\subsubsection{输出格式：}

选择打印版（print）或用于提交的电子版（electronic），前者会插入空白页以便直接双面打印。

待赋值变量：output

\subsubsection{封面格式：}

选择用于预审（preliminary）或用于最终提交的终版（final）。

待赋值变量：cover

\subsubsection{学位类型：}

选择本科（bachelor）、硕士（master）或者博士（doctor），会影响封面不同，其他部分不影响。如果是单纯完成论文，不申请学位，写 none 即可。

待赋值变量：degree

\subsubsection{论文标题：}

-1 和 -2 分别对应标题的第一行和第二行，加 * 的为英文标题。如需更多行，可添加 title-3、title-4 等（中文）和 title-3*、title-4* 等（英文）。

待赋值变量：title-1、title-2、title-1*、title-2*（可扩展）

\subsubsection{论文编号：}

待赋值变量：thesis-id

\subsubsection{学校代码：}

待赋值变量：school-id

\subsubsection{学科专业：}

待赋值变量：discipline

\subsubsection{研究方向：}

待赋值变量：professional-field

\subsubsection{作者姓名：}

待赋值变量：author

\subsubsection{作者学号：}

待赋值变量：student-id

\subsubsection{指导教师：}

中文姓名和职称之间以 \verb|\quad| 分开。

待赋值变量：supervisor

\subsubsection{完成日期：}

待赋值变量：date

上述字段，如果有不需要的，直接置空为 \verb|{}| 即可。

\indent \indent 正文：

\indent \indent \indent \indent 章节1：data/chap01.tex

\indent \indent \indent \indent 章节2：data/chap02.tex

\indent \indent \indent \indent 章节3：data/chap03.tex

\indent \indent \indent \indent 章节4：data/chap04.tex

\section{章节设置}

章节采用递进式设计，结构如下：

\subsubsection{篇：}

命令：\verb|\part{篇标题}|

显示内容：第X部分 篇标题

显示格式：篇名单独成页，上下左右居中，黑体二号字。

\subsubsection{章：}

命令：\verb|\chapter{章标题}|

显示内容：第X章 章标题

显示格式：居中，黑体小二号字。凡章名，起于一页之首，一章结束，设分页符，下一章另起一页。

\subsubsection{节：}

命令：\verb|\section{节标题}|

显示内容：第X节 节标题

显示格式：居中，楷体小三号字。硕士学位论文若不设节名，则章名下直接用条名。

\subsubsection{条：}

命令：\verb|\subsection{小节标题}|

显示内容：X、小节标题

显示格式：左缩进两个字符，宋体四号字，加粗。条名使用标题序号为“一、”“二、”“三、”等。

\subsubsection{小标题：}

命令：\verb|\subsubsection{小标题}|

显示内容：（X）小标题

显示格式：格式同正文。

以上命令可在需要的时候自行添加，目录页会自动对应其页码。

由于篇名通常不需要，可在范例的 data/chap01.tex 和 data/chap03.tex 内的第一行删除对应内容。

\section{字体设置}

在本模板中，正文为宋体小四号字，常用的使用其他字体命令如下：

\subsubsection{斜体：}

（在本模板中，斜体会显示为楷体，在需要引用的时候使用）

命令：\verb|\textit{文字}|

快捷键：选中文字后 Ctrl+i（苹果电脑为 Command+i）

\subsubsection{加粗：}

命令：\verb|\textbf{文字}|

快捷键：选中文字后 Ctrl+b（苹果电脑为 Command+b）

\section{脚注设置}

在需要添加脚注的地方插入 \verb|\footnote{脚注内容}|，则会自动在页脚部分插入脚注内容。

\section{注释内容}

使用 \% 在语句前可以注释掉不需要显示在 PDF 内的文字，例如：

\begin{python}
% 语句一
语句二
\end{python}

编译后在 PDF 内显示：

\begin{python}
语句二
\end{python}

使用快捷键为 Ctrl+/（苹果电脑为 Command+/）

\section{段落设置}

在 LaTeX 中，单行换行无法切换段落，需要间隔一行，例如：

\begin{python}
段落一
段落二

段落三
\end{python}

编译后在 PDF 内显示效果为：

\begin{python}
段落一段落二

段落三
\end{python}
